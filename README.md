# Compliance University™ / NewYorkHUT.com

NewYorkHUT.com is the educational authority property for New York Highway Use Tax. NYHUT.com is the transactional permit-ordering platform.

Build pipeline:

```text
build.mjs -> seo-extra.mjs -> validate.mjs -> dist/
```

The validation step enforces canonical URLs, sitemap uniqueness, the absence of transactional Product/Offer schema on NewYorkHUT.com, and the presence of NYHUT.com conversion links on educational pages.
